이서당 녹화 앱 3.0.7 키오스크 디자인 변경 인계 (C1~C20)

1) 적용 방법 (개발자)
   - apply-design.mjs 를 eseodang30-app 폴더(맨 위)에 복사
   - 터미널에서:  node apply-design.mjs
   - 끝나면 git diff 로 변경 내용 확인 후 앱 실행해서 화면 확인
   - 여러 번 실행해도 안전합니다(이미 적용된 항목은 건너뜀)
   - "✗" 로 표시된 항목이 있으면 그 항목만 코드 모양이 예상과 달라 바꾸지 않은 것입니다.
     해당 줄을 디자이너에게 전달해 주세요.

2) 스크립트가 새로 만드는 파일 (src/renderer/src/design/)
   - LevelMeter.tsx   마이크 레벨 막대 (C9)
   - StepIndicator.tsx 진행 단계 표시 (C13)
   - PreviewStatus.tsx 영상이 비어 있을 때 상태 (C18)
   - BrandMark.tsx    헤더 왼쪽 심볼 (C19)

3) preview-prototype.html (클릭형 미리보기)
   - 브라우저로 열면 변경이 모두 들어간 화면을 눌러 보며 확인할 수 있습니다.
   - 시안용 가짜 영상이 나오므로 '프리뷰 연결 중' 화면은 이 파일에서는 보이지 않습니다
     (디자인 캔버스의 '프리뷰 빈 상태' 보드에서 확인).

변경 항목별 설명(전/후)은 인계 문서에 있습니다.
