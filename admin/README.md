이서당 키오스크 관리자 화면의 디자인 규칙입니다. 서체 Pretendard와 브랜드 보라(`violet` #9044eb)는 이서당 것을 그대로 쓰고, 바탕은 어두운 보라색에서 다크그레이로 바꿨습니다. 관리자는 이 화면을 오래 보기 때문에 눈이 덜 피로한 차분한 색, 큰 모니터에 맞는 넉넉한 글자와 여백, 색을 바꾸지 않는 반투명 오버레이 hover를 기본으로 삼았고, 다크그레이 바탕 덕분에 관리자 화면 안에 띄운 키오스크 화면(어두운 보라색)과 경계가 또렷하게 나뉩니다.

## 핵심 원칙

1. **바탕은 다크그레이, 보라는 포인트에만.** 페이지 `bg` #232323 위에 패널 `surface` #363636. 보라 채움은 주요 버튼 하나, 켜진 스위치, 선택 탭 막대에만 씁니다.
2. **상태는 옅은 바탕 + 진한 글자.** 칩은 `*-tint` 바탕에 `*-text` 글자 한 가지 모양뿐입니다. 상태를 색으로만 나타내지 말고 단어와 함께 씁니다.
3. **hover는 색을 바꾸지 않고 반투명 오버레이, 누르면 살짝 작아짐.** 모든 컨트롤은 hover 때 밝은 오버레이 8%(`state-hover`), 누를 때 16%(`state-press`)를 얹습니다. 버튼처럼 누르는 요소는 누르는 동안 97%로 작아져 눌렸다는 느낌을 줍니다(Emil Kowalski 규칙). hover에는 크기 변화를 쓰지 않습니다.
4. **라운드는 8px 하나.** 버튼, 입력, 칩, 패널, 토스트, 확인 창 모두 `radius-md`. 둥근 모양은 스위치와 녹화 표시(6px 점)뿐입니다.
5. **구분은 라인으로, 그림자는 떠 있는 것에만.** 패널과 카드는 1px `line` 테두리. 그림자는 토스트, 드롭다운, 확인 창에만.
6. **굵기는 400 · 500 · 700 세 단계.** 600은 쓰지 않습니다. 본문 400, 버튼·라벨·탭·패널 제목 500, 페이지 제목·숫자 700.

## 색

- 바탕 단계: 페이지 `bg` #232323 → 패널·카드·상단 바 `surface` #363636 → 보조 버튼·기본 칩 `surface-3` #474747. 읽기 전용 칸처럼 살짝 들어간 영역은 `surface-2` #282828. 입력창 바탕은 `bg`라 패널 위에서 한 단 들어가 보입니다.
- 글자 단계: 본문 `text` #fafafa, 라벨·표 머리·비선택 탭 `text-2` #bebebe, 플레이스홀더·메타·힌트 `text-3` #a7a7a7. 세 단계 모두 `bg`·`surface` 위에서 4.5:1을 넘습니다. 단 `text-3`은 `surface-3` 위에서 3.86:1이라 그 위에는 쓰지 않습니다.
- 선 단계: 패널·표 라인 `line` #474747, 팝업·원격 화면 테두리 `line-strong` #606060, 입력 링·스위치 꺼짐 `line-input` #6c6c6c.
- 보라: 나머지 보라 단계는 #9044eb와 같은 색상각에서 밝기만 바꿔 계산했습니다. 채움 `violet`, 포커스 링 `violet-line` #8749d7, 링크·선택 탭 글자 `violet-text` #b994fa, 보라 칩 글자 `violet-text-2` #ccb2fe, 보라 칩 바탕 `violet-tint`(#9044eb 20%). `violet`은 글자로 쓰지 않습니다(바탕 위 3.15:1).
- 상태색: 성공 `ok` #46b993, 위험 `rec` #fd8283. 칩은 `ok-tint`·`ok-text`, `rec-tint`·`rec-text`.
- 칩 바탕(`*-tint`)은 단색이 아니라 상태색 500 단계를 투명도 20%로 얹습니다. 그래서 페이지 바탕 위든 패널 위든 같은 옅기로 보입니다.
- 경고는 노랑(`warn` #dd9a00, 칩 `warn-tint`·`warn-text`)을 씁니다. 주황은 다크 바탕에서 위험 빨강과 거의 같아 보여 "녹화기 끊김"과 "차단됨"이 구분되지 않기 때문입니다.
- 원격 화면과 로그 영역만 `screen-bg`(#000).
- 그라데이션, 반투명 유리 효과, 블러는 쓰지 않습니다. 키오스크의 보라→주황 그라데이션은 키오스크 전용입니다.

## 글자

- 서체는 Pretendard. 400, 500, 700 세 굵기 파일을 각각 등록합니다. 코드·기기 ID는 Fira Code(없으면 D2Coding).
- 큰 모니터에서 오래 보는 화면이라 넉넉한 크기를 씁니다: `t-num` 28/36 700 · `t-title` 22/32 700 · `t-dialog` 20/28 700 · `t-heading` 18/26 500 · `t-body` 15/24 400 · `t-label` 15/24 500 · `t-caption` 13/20 400 · `t-overline` 13/20 500 · `t-mono` 13/20. 이 단계 밖의 크기는 만들지 않습니다.
- 자간은 px로, 클수록 좁게: 28px -0.3px, 22px -0.2px, 20·18·15px -0.1px, 13px 칩 글자와 코드는 0.
- 숫자(현황, 시간, 버전, IP)에는 `.num`(tabular-nums).
- 선택된 탭이나 메뉴도 굵기를 올리지 않습니다. 선택은 색과 막대로만 표시합니다.

## 여백, 크기, 라운드

- 여백은 2px 단위입니다. 쓰는 단: 2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 28 · 32 · 48 (`space-0-5` ~ `space-12`). 28(`space-7`)은 빡빡하지 않게 하려고 더한 단입니다.
- 패널·카드 안쪽 28px(`space-7`), 패널 머리 위 20px · 좌우 28px. 페이지 가장자리와 상단 바 좌우 32px, 카드 사이 16px.
- 표 셀은 머리와 본문 모두 위아래 12px · 좌우 28px(한 줄 약 48px). 설정 한 줄은 위아래 16px · 좌우 28px.
- 컨트롤 높이: `control-h-sm` 28 · `control-h` 36 · `control-h-lg` 44. 버튼 좌우 여백 12 · 16 · 16. 상단 바 60. 왼쪽 메뉴 248px, 설정 목차 220px, 본문 최대 폭 1440px.
- 라운드는 `radius-md` 8px가 기본값입니다. `radius-sm` 6px는 24px 로고, `radius-xs` 4px는 체크박스에만.

## 상호작용

| 상태 | 처리 |
| --- | --- |
| hover | 밝은 오버레이 8%(`state-hover`). 표 행처럼 촘촘한 면은 4%(`state-hover-dense`). 즉시 바뀌지 않고 0.15초 `ease`로 부드럽게 올라오고 내려감. 글자색이 바뀌는 탭·메뉴·링크도 같은 0.15초 |
| 누름 | 밝은 오버레이 16%(`state-press`) + 97%로 축소(`scale(.97)`, 0.16초, 강한 ease-out `cubic-bezier(0.23,1,0.32,1)`). 큰 현황 카드는 99%. 비활성 버튼과 현재 페이지 번호는 줄어들지 않음 |
| 비활성 | 전체 투명도 0.32, 오버레이 꺼짐 |
| 포커스 | 2px `text` 외곽선, 2px 띄움. 입력·셀렉트만 1px 안쪽 링이 `violet-line`으로 |
| 토글 켜짐 | 버튼은 `violet-tint` 바탕 + `violet-text-2` 글자, 스위치는 `violet` 트랙 |

- 전환 시간은 0.15~0.16초, 토스트가 쌓일 때만 0.4초. 색이 바뀌는 hover는 `ease`, 들어오고 나가는 움직임과 누름은 강한 ease-out(Emil Kowalski 규칙). `transition: all`은 쓰지 않고 바뀌는 속성만 적습니다. 튀는(bounce) 움직임은 쓰지 않습니다.
- 동작 줄이기 설정을 켠 사용자에게는 축소를 하지 않고 반투명 오버레이만 남깁니다.
- 누름 축소와 움직임 곡선은 Emil Kowalski의 디자인 엔지니어링 규칙을 따랐습니다.

## 상태 표현

| 상황 | 칩 | 뜻 |
| --- | --- | --- |
| 연결됨 | `.chip.ok` "연결됨" | 정상 연결. 초록은 "연결됨" 한 가지 뜻만 가집니다 |
| 대기 | `.chip` "대기" | 연결됐지만 할 일 없음. 평상시 상태라 눈에 띄지 않게 무채색 |
| 녹화 중 | `.chip.live` "녹화 중" | 중립 칩 + 빨간 녹화 표시(6px). 정상 작동이므로 빨간 바탕을 쓰지 않습니다 |
| 연결 안 됨 | `.chip.off` "연결 안 됨" | 바탕 없이 테두리만. 꺼져 있다는 느낌 |
| 녹화기 끊김, 확인 필요, 재시작 후 반영 | `.chip.warn` | 곧 손봐야 하는 상태 |
| 차단됨, 실패 | `.chip.rec` | 빨간 바탕은 문제·관리자 조치 전용 |
| 바뀜(저장 전) | `.chip.violet` | 보라는 선택·변경 표시에만 |
| 버전 | `.chip` | 정보일 뿐이라 중립 |

- 상태는 칩 하나로만 말합니다. 예전의 행 앞 상태 점(`.dot`)은 칩과 같은 말을 반복해서 목록과 상세 헤더에서 뺐습니다(클래스는 호환을 위해 남겨 둠).
- 현황 카드의 "녹화 중" 숫자도 빨간 글자 대신 라벨 앞 녹화 표시(`.rec-mark`)로 구분합니다.
- 원격 조작 중인 화면 프레임은 `warn` 테두리로, 조작 중임을 분명히 합니다.
- 되돌리기 어려운 동작은 `.btn.danger`(빨간 안쪽 링) + 확인 창(`Dialog`)을 거칩니다.

## 대비가 부족한 곳 (알고 둔 것)

- `line-input` 입력 링: 바탕 대비 2.99:1로 컨트롤 경계 기준 3:1에 아주 조금 못 미칩니다.
- 성공·오류 토스트(`ok-fill`, `rec-fill`) 위 흰 글자: 3.5:1. 토스트 문장은 짧게, 중요한 오류는 화면 안에도 남깁니다.
- 위험 동작 버튼은 같은 문제 때문에 채운 빨강 대신 outline 모양을 씁니다.

## 기능이 늘 때 쓰는 공통 화면 구성 요소

새 기능 화면은 아래 화면 구성 요소와 화면 틀 3가지(목록형 · 상세형 · 폼형)를 조립해서 만듭니다. 새 모양을 즉석에서 만들지 말고, 없는 화면 구성 요소가 필요하면 이 문서에 먼저 추가합니다.

화면 구성 요소 카드 부제 맨 앞의 **사용 중**은 지금 화면에 쓰는 화면 구성 요소, **준비됨**은 지금은 쓰지 않고 기능이 늘 때 꺼내 쓰는 화면 구성 요소입니다. 준비된 화면 구성 요소의 스타일도 `bundle.css`에 들어 있어 따로 받을 필요가 없습니다.

| 필요할 때 | 화면 구성 요소 |
| --- | --- |
| 메뉴가 늘어남 | `Sidebar`(왼쪽 메뉴, `.app` 틀) |
| 목록에서 찾기·거르기 | `TableTools`의 필터 바 |
| 여러 개를 한꺼번에 처리 | `TableTools`의 선택 열 + 일괄 작업 바 |
| 목록이 길어짐 | `TableTools`의 정렬 · 페이지 넘김 |
| 행마다 동작이 여러 개 | `Menu`(⋯ 더보기) |
| 아이콘만 있는 버튼 | `Menu`의 툴팁 |
| 화면을 떠나지 않고 상세 보기 | `Sheet`(오른쪽 패널) |
| 입력이 많은 등록·수정 화면 | `Field`(오류 표시) · `Choice`(체크박스·라디오) · 폼 틀(`.form-grid` + 아래 저장 바 `.savebar`) |
| 데이터가 없음·불러오는 중·실패 | `States` |
| 페이지 단위로 남겨야 할 안내 | `Callout` |
| 잠깐 알리고 사라질 결과 | `Toast` |
| 되돌리기 어려운 동작 확인 | `Dialog` |
| 설정이 20개 넘는 화면 | `SettingRow`의 설정 화면 틀(묶음 목차 · 위 고정 변경 바 · 반영 방식 칩 · 딸린 설정 · 접힌 고급 설정) |

- 아이콘은 `.ic`(16px, 선 1.5px, Lucide 세트). 아이콘만 있는 버튼은 `.btn.icon` + `aria-label` + 툴팁.
- 선택된 행·일괄 작업 바·왼쪽 메뉴 현재 항목은 같은 `violet-tint-dense`(보라 10%) 바탕을 씁니다.

## 문구

- 존댓말 평서문, 짧게: "키오스크가 연결되어 있을 때 설정을 볼 수 있습니다."
- 버튼은 짧은 동사로 끝: "화면 보기", "저장", "재시작", "목록에서 지우기".
- 위험 동작은 결과를 미리 말함: "녹화기를 재부팅할까요? 1~2분 동안 녹화할 수 없습니다."
- 이모지, 느낌표, "~해보세요!" 같은 권유형 말투는 쓰지 않습니다.

## 아이콘과 로고

- 아이콘은 24×24 선 굵기 1.5px 한 세트(Lucide)만 씁니다. 컨트롤 안에서는 16px(`.ic`), 빈 화면 같은 큰 자리에서는 24px(`.ic.lg`), 색은 `currentColor`. "←" 같은 글자 기호로 아이콘을 대신하지 않습니다(새 화면 구성 요소는 모두 SVG 아이콘으로 바꿨고, 기존 화면의 "← 키오스크 목록"도 같은 방식으로 바꿉니다).
- 로고 파일은 받지 못했습니다. 상단의 `violet` 단색 사각형(`.logo`)은 임시 표시입니다.

## 하지 말 것

- 토큰에 없는 색과 글자 크기, 600 굵기
- hover 때 다른 색으로 바꾸거나 크기 키우기, 0.95보다 크게 줄이기
- 8px보다 큰 라운드, 패널·카드에 그림자
- 그라데이션, 블러, 글로우
- 흰 글자를 얹은 진한 칩, 채운 빨간 버튼
- 상태를 색으로만 표시
