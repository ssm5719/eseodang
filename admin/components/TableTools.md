# TableTools

목록 화면에서 표와 함께 쓰는 도구 묶음입니다. 필터 바(`.filterbar`), 선택 열(`th.sel`·`td.sel`), 일괄 작업 바(`.bulkbar`), 정렬 머리(`button.sort`), 표 아래 줄(`.table-foot`)과 페이지 넘김(`.pager`).

- **필터 바**: 찾기 입력(`.input-icon` + 돋보기 아이콘)은 왼쪽, 셀렉트 필터가 그 뒤. 적용 중인 추가 조건은 `.filter-chip`(누르면 지워짐)으로 보여 주고, 끝에 `초기화`.
- **선택**: 첫 열 체크박스. 선택된 행은 `aria-selected="true"`로 `violet-tint-dense` 바탕. 머리 체크박스는 일부만 선택되면 `indeterminate`.
- **일괄 작업 바**: 하나 이상 선택되면 표 머리 위에 나타납니다. "N개 선택됨" + 작은 버튼(`.btn.sm`) + 오른쪽 끝 `선택 해제`. 위험 동작은 `.btn.sm.danger`이고 확인 창을 거칩니다.
- **정렬**: 정렬 가능한 머리만 `button.sort`. 기본은 위아래 화살표(회색), 정렬 중인 열은 `aria-sort` + 방향 화살표(보라) + 글자 `text`. 한 번에 한 열만.
- **페이지 넘김**: 왼쪽에 "1–20 / 128"(범위 / 전체), 오른쪽에 `.pager`. 현재 페이지는 `aria-current="page"`로 보라 옅은 바탕. 7쪽 이상이면 가운데를 "…"로 줄입니다. 지금 키오스크 목록은 한 화면에 다 들어갈 만큼 짧아서 당장은 쓰지 않고, 목록이 한 화면(20줄)을 넘을 때 붙입니다. 모양은 '틀 · 키오스크 목록' 보드에 담아 둡니다.
- **행 더보기**: 행 끝 `⋯` 아이콘 버튼(`.btn.icon.sm.ghost`)을 누르면 `Menu`가 열립니다.
