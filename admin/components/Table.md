# Table

키오스크 목록과 작업 기록처럼 여러 행을 비교하는 표로, `.panel` 안에 `table`을 둡니다.

- 머리와 셀이 같은 여백(위아래 12 · 좌우 28, 한 줄 약 48px), 같은 15px. 머리는 500 `text-2`, 셀은 400 `text`. 머리 배경색은 깔지 않습니다.
- 행을 대표하는 첫 열 이름만 500, 그 아래 보조 줄은 `.sub`(13px `text-3`).
- 행 구분선 `line`. 클릭 가능한 행(`tr.click`)은 hover 때 밝은 오버레이 4%(촘촘한 면용 반투명 오버레이).
- 숫자, 시간, IP, 버전 열은 `.num`. 날짜까지 쓸 때 `2026-10-15 15:04` 형식.
- 빈 값은 `-`를 `text-3`으로.
