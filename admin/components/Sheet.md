# Sheet

목록에서 행을 눌렀을 때 화면을 떠나지 않고 오른쪽에서 여는 상세 패널입니다. 확인 창(`Dialog`)보다 내용이 많고, 상세 화면보다 가볍게 볼 때 씁니다.

- 폭 420px, `surface` 바탕, 왼쪽 1px `line-strong` + `shadow-xl`, 라운드 없음.
- 머리(`.sheet-head`) 높이 60: 제목 18px 500 + 닫기 아이콘 버튼. 본문(`.sheet-body`)은 안쪽 20 · 28, 묶음 사이 24, 묶음 제목은 `.section-label`.
- 아래(`.sheet-foot`) 오른쪽에 [닫기] [주요 동작]. 뒤 화면은 `scrim`(검정 32%)으로 덮고, Esc나 바깥 누름으로 닫습니다.
