# Toast

동작 결과를 잠깐 알리는 메시지로, 화면 아래 가운데에 뜹니다.

- 바탕색으로 종류를 나눕니다. 기본 `.toast`는 `contrast`(#606060), 성공 `.toast.ok`는 `ok-fill`, 오류 `.toast.err`는 `rec-fill`. 글자는 모두 흰색 15px 500.
- 라운드 8px, 안쪽 16px, `shadow-pop`, 최대 폭 400px.
- 주의: 성공·오류 바탕 위 흰 글자는 3.5:1로 본문 기준 4.5:1에 못 미칩니다(알고 둔 값). 문장을 짧게 쓰고, 중요한 오류는 화면 안에도 남깁니다.
- 성공 2.5초, 오류 6초 뒤 사라집니다. 성공은 `role="status"`, 오류는 `role="alert"`.
- 문장은 결과를 말합니다: "3개 설정을 저장했습니다", "재시작 요청을 보냈습니다".
