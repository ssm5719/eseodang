# Field

글자 입력, 셀렉트, 여러 줄 입력으로, `.input`과 `.select`에 `.label`을 짝지어 씁니다. 라벨·입력·안내 문구를 `.field`로 묶습니다.

- 라벨은 입력 위에 `.label`(15px 500 `text-2`). 꼭 채워야 하는 칸은 라벨 뒤 빨간 `*`(`.req`). 플레이스홀더만으로 라벨을 대신하지 않습니다.
- 바탕은 페이지 바탕(`bg`)이라 패널 위에서 한 단 들어가 보입니다. 테두리는 1px 안쪽 링(`line-input`).
- hover 때 링이 조금 밝아지고, 포커스 때 링이 `violet-line`으로 바뀝니다.
- 안내 문구는 입력 아래 `.field-msg`(13px `text-3`). 글자 수 제한이 있으면 오른쪽에 "0 / 200".
- **오류**: `aria-invalid="true"`면 링이 빨강(`rec-line`), 안내 문구는 `.field-msg.err`(빨강)로 바꿔 무엇이 틀렸고 어떻게 고치는지 씁니다. 입력을 마치고 칸을 벗어날 때 검사하고, 타이핑 중에는 빨갛게 만들지 않습니다.
- 높이 36px, 로그인처럼 큰 입력은 `.lg` 44px. 라운드 8px.
- 읽기 전용은 `surface-2` 바탕, 비활성은 투명도 0.32.
- 주의: `line-input` 링은 바탕 대비 2.99:1로 3:1 기준에 아주 조금 못 미칩니다(알고 둔 값).
