# Menu

행 끝 `⋯`나 버튼을 누르면 열리는 드롭다운 메뉴(`.menu`)와, 아이콘만 있는 버튼에 붙는 툴팁(`.tooltip`)입니다.

- 메뉴: `surface` 바탕 + 1px `line-strong` 테두리 + 라운드 8 + `shadow-pop`, 안쪽 4px, 최소 폭 200px.
- 항목(`.menu-item`) 높이 36, 15px 400, 왼쪽 16px 아이콘(`text-2`). hover·키보드로 고른 항목은 밝은 오버레이 8%, 굵기는 올리지 않습니다.
- 위험 항목(`.menu-item.danger`)은 빨간 글자로 맨 아래에, 구분선(`.menu-sep`) 뒤에 둡니다. 누르면 확인 창을 거칩니다.
- 묶음 제목이 필요하면 `.menu-label`(13px 500 `text-3`).
- 툴팁: `contrast` 바탕 + 흰 13px 400, 라운드 8. 아이콘만 있는 버튼에는 꼭 툴팁과 `aria-label`을 붙입니다. 긴 설명은 툴팁 대신 화면에 글로 씁니다.
