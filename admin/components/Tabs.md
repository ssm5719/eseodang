# Tabs

키오스크 상세 화면의 영역 전환 탭으로, `.tabs` 안에 `.tab`을 나열합니다.

- 높이 44px(`control-h-lg`), 15px 500. 탭마다 좌우 8px, 탭 사이 12px(글자 사이 28px). 탭 줄이 넘쳐도 스크롤 막대는 보이지 않게 하고 옆으로 밀 수만 있게 합니다.
- 선택 상태는 `aria-selected="true"`: 글자 `violet-text` + 아래 2px `violet` 막대. 선택돼도 굵기는 올리지 않습니다.
- 비선택은 `text-2`, hover 때 `text`.
- 키보드 포커스 외곽선은 탭 안쪽(-2px)에 그립니다.
- 탭 이름은 두 단어 이내 명사.
