# Badge

상태를 짧은 단어로 보여주는 칩(`.chip`)입니다. 상태는 칩 하나로만 말합니다.

- 칩은 한 가지 모양뿐입니다: 옅은 바탕(`*-tint`, 상태색 500 단계를 20% 투명도로) + 진한 글자(`*-text`) 한 가지 모양뿐, 흰 글자를 얹은 진한 칩은 만들지 않습니다.
- 높이 28px(`control-h-sm`), 좌우 8px, 라운드 8px(`radius-md`), 13px 500(`t-overline`).
- 색마다 뜻은 하나입니다.
  - `.ok` 연결됨·성공·최신 — 정상
  - `.rec` 차단됨·실패 — 문제·관리자 조치 전용. 정상 작동인 "녹화 중"에는 쓰지 않습니다
  - `.warn` 녹화기 끊김·확인 필요·재시작 후 반영 — 곧 손볼 것
  - `.violet` 바뀜 — 저장 전 변경 표시
  - 기본(회색) 대기·버전 — 평상시 정보
  - `.live` 녹화 중 — 회색 칩 앞에 6px 빨간 녹화 표시. 방송·녹화의 관례 색은 남기되 문제처럼 보이지 않게
  - `.off` 연결 안 됨 — 바탕 없이 테두리만
- 예전의 상태 점(`.dot`)은 칩과 같은 말을 반복해서 화면에서 뺐습니다. 클래스는 호환을 위해 남겨 두지만 새 화면에는 쓰지 않습니다.
- 현황 카드처럼 칩이 아닌 곳에서 녹화 중을 표시할 때는 라벨 앞에 `.rec-mark`를 둡니다.
