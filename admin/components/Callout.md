# Callout

화면 안에 남아 있는 안내 상자입니다. 잠깐 떴다 사라지는 `Toast`와 달리, 사용자가 읽고 조치할 때까지 남겨야 하는 내용에 씁니다.

- `.callout` + 종류: `.violet` 안내, `.ok` 완료, `.warn` 주의(연결 끊김 등), `.rec` 오류.
- 1px 테두리 + 20% 옅은 바탕 + 같은 계열 글자, 라운드 8, 안쪽 12 · 16. 왼쪽에 16px 아이콘.
- 첫 줄은 500으로 결론, 둘째 줄(`p`)은 400 `text-2`로 이유나 다음 행동.
- 폼 맨 위의 오류 요약, 연결 끊김, 새 버전 알림처럼 페이지 단위 소식에 씁니다.
