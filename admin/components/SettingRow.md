# SettingRow

설정 탭의 한 줄과, 설정이 많은 화면을 정리하는 틀입니다. `.setting` 안에 `.setting-name`, `.setting-hint`, 컨트롤(오른쪽 360px).

**화면 틀(설정이 20개 넘을 때)**
- `.settings-layout`: 왼쪽 220px 묶음 목차(`.settings-nav`, 위에 "설정 찾기") + 오른쪽 묶음. 목차에는 묶음별 설정 수(오른쪽 회색 숫자). 저장하지 않은 변경이 있는 묶음은 이름 바로 뒤에 8px 보라 점(`.dirty-dot`, `violet-text`)을 붙이고, 마우스를 올리면 "바뀐 설정 N개"가 보이게 `title`과 `aria-label`을 줍니다. 몇 개가 바뀌었는지는 위 변경 바가 알려 줍니다.
- **묶음은 하나씩 보여 줍니다.** 각 묶음은 `section.settings-pane`이고 고른 묶음에만 `.is-active`. 한 묶음이 한 화면 안팎이라 위로 가기 버튼은 두지 않습니다. 설정이 3~4개뿐인 묶음은 성격이 가까운 묶음에 합치고, 묶음 안에서 다시 나눌 땐 `.section-sub`(작은 회색 제목 + 위 구분선).
- 다른 묶음에서 바꾼 내용은 목차의 보라 점과 위 변경 바로 계속 보여 줍니다. 저장하지 않은 채 다른 탭이나 화면으로 나가면 확인 창(`Dialog`)으로 묻습니다.
- "설정 찾기"에 입력하면 묶음 구분 없이 전체에서 찾아, 묶음 이름(`.search-group`) 아래로 결과 줄만 모아 보여 주고 찾은 글자는 `mark`로 표시합니다. 입력을 지우면 원래 묶음으로 돌아갑니다.
- 마지막에 본 묶음을 기억해 다시 들어오면 그 묶음부터 보여 줍니다.
- 맨 위 `.changebar`(스크롤해도 위에 고정): 바뀐 개수와 저장하면 어떻게 반영되는지 한 문장 + [다시 읽기] [저장] [녹화기에 적용] [프로그램 재시작]. 바뀐 게 있으면 `.dirty`로 보라 테두리. 적용은 저장 전엔 비활성.
- 범례 줄은 두지 않습니다. 반영 방식 칩의 이름이 스스로 뜻을 말하고, 마우스를 올리면 `title`로 한 문장 더 알려 줍니다.

**한 줄 규칙**
- 이름 15px 500, 힌트 13px `text-3`. 힌트에는 무엇이 바뀌는지만 쓰고 "바로 반영" 같은 반영 방식은 쓰지 않습니다.
- 반영 방식은 이름 옆 작은 칩(`.chip.sm`)으로: 표시 없음 = 저장하면 바로 반영, "저장 후 적용"(회색), "재시작 후 반영"(노랑). 대부분인 '바로 반영'은 표시하지 않아 눈에 걸리는 게 줄어듭니다.
- 저장 전 바뀐 줄은 `.changed`(왼쪽 보라 2px 막대) + "바뀜" 칩.
- 다른 설정이 켜져야 의미 있는 설정은 `.child`로 한 단 들여 쓰고 왼쪽에 세로선. 부모가 꺼지면 `aria-disabled="true"`로 흐리게(0.32).
- 같은 성격의 짧은 값(채널 이름 5개, 포트 3개)은 줄을 나누지 말고 `.fields-inline`(칸 수는 `--cols`)으로 한 줄에. 넓게 쓸 땐 `.setting.stack`.
- 숫자 칸은 `.input.w-sm`(96px) + 단위(`.unit`, 예: "분 전").
- 자주 안 바꾸거나 잘못 바꾸면 위험한 설정(외부 접속, 관리 서버 연결)은 접지 않고 같은 묶음 아래 **별도 박스**(`.panel` 하나 더, 위 16px 띄움)로 나눕니다. 박스 머리에는 제목과 반영 방식 칩만 두고, 기존 화면에 없던 설명이나 경고 문구는 덧붙이지 않습니다. 접어 두면 현재 값을 확인하려고 매번 펼쳐야 해서 쓰지 않습니다.
- 한 묶음(박스) 안 대부분이 같은 반영 방식이면 칩을 항목마다 달지 않고 박스 제목 옆에 한 번만 답니다. 예외 항목에만 바탕 없는 테두리 칩(`.chip.sm.off`) "바로 반영"을 붙입니다.
- 켜고 끄는 설정은 `.switch`. 좁은 화면(900px 이하)에서는 목차가 위 가로 줄로, 컨트롤이 이름 아래로 내려갑니다.
