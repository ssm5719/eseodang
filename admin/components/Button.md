# Button

동작을 실행하는 버튼으로, `.btn`에 변형 클래스를 더해 씁니다.

- 크기: 기본 높이 36px(`control-h`), `.sm` 28px, `.lg` 44px. 글자는 크기와 상관없이 15px 500(`t-label`), 라운드는 늘 8px(`radius-md`).
- `.btn.primary`: 보라 채움 + 흰 글자. 화면에서 가장 중요한 동작 하나에만(화면 보기, 저장, 로그인).
- `.btn`: 회색(`surface-3`) 채움. 그 밖의 일반 동작.
- `.btn.danger`: 되돌리기 어려운 동작(차단, 지우기, 재부팅). 빨간 안쪽 링 + 빨간 글자 모양. 채운 빨강은 흰 글자 대비가 3.5:1이라 쓰지 않습니다. 누르면 반드시 확인 창을 거칩니다.
- `.btn.outline`: 보라 안쪽 링 + 보라 글자. primary 옆에 두는 두 번째 동작.
- `.btn.warn`: 원격 조작 끄기처럼 '지금 위험한 상태를 끄는' 동작.
- `.btn.ghost`: 바탕 없이 글자만. 다시 읽기, 로그아웃 같은 보조 동작.
- `aria-pressed="true"`: 토글 상태. 보라 옅은 바탕 + 보라 글자.
- hover·눌림은 색을 바꾸지 않고 밝은 오버레이를 8%·16% 얹습니다. 누르는 동안에는 97%로 살짝 작아집니다(0.16초, 강한 ease-out). 비활성 버튼은 줄어들지 않고, 동작 줄이기 설정이면 축소 없이 반투명 오버레이만 합니다.
- 비활성은 `disabled` 속성. 전체 투명도 0.32.
