# States

데이터가 없거나, 불러오는 중이거나, 실패했을 때 표나 패널 자리에 대신 보여 주는 화면입니다.

- **빈 화면**(`.state`): 24px 회색 아이콘 + 제목 18px 500 + 설명 `text-2` + 다음 행동 버튼 하나. "데이터 없음"이 아니라 이유와 할 일을 씁니다. 처음 쓰는 경우("아직 등록된 키오스크가 없습니다")와 필터 결과가 없는 경우를 문구로 나눕니다.
- **불러오는 중**: 1초 이내면 아무것도 보여 주지 않고, 길어지면 `.spinner` + "불러오는 중", 표나 목록 자리는 `.skeleton` 줄로 채웁니다. 감싸는 요소에 `aria-busy="true"`. 동작 줄이기 설정이면 애니메이션을 멈춥니다.
- **오류**(`.state.err`): 빨간 아이콘 + 무엇이 안 됐는지 + 다시 시도 버튼. 기술 오류 코드는 설명 끝에 작게만.
- 패널 일부만 실패했을 땐 이 화면 대신 `Callout`을 씁니다.
