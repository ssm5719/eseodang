# Sidebar

메뉴가 늘어날 때 쓰는 왼쪽 메뉴입니다. 화면 왼쪽 끝에서 끝까지(위아래 100%) 놓는 메뉴입니다. `.app`(248px + 본문) 틀 안에 `nav.side`와 `.app-main`을 두고, 상단 바(`.topbar`)는 `.app-main` 안, 본문 위에만 둡니다.
- **메뉴 머리**(`.side-head`): 메뉴 맨 위, 상단 바와 같은 높이(60px)에 로고 + 서비스 이름(15px 500)과 오른쪽 끝 접기 버튼(`.side-btn`, 패널 아이콘)을 둡니다. 메뉴 아래쪽에는 따로 접기 버튼을 두지 않습니다.

- 항목(`.side-link`) 높이 44, 16px 아이콘 + 15px 500 `text-2`. 오른쪽 끝 숫자는 `.count`(13px `text-3`).
- 현재 화면은 `aria-current="page"`: 보라 글자(`violet-text-2`) + `violet-tint-dense` 옅은 바탕. 굵기는 올리지 않습니다.
- 묶음 제목은 `.side-label`(13px 500 `text-3`). 묶음은 둘 이하로.
- 첫 메뉴는 "키오스크"(목록 위에 현황 숫자 카드 4개를 둔 화면)입니다. 따로 "현황" 대시보드는 두지 않고, 메뉴가 많이 늘어나 한눈에 볼 요약이 필요해지면 그때 추가합니다.
- **접기·펼치기**: 메뉴가 꼭 필요한지 아직 정해지지 않아 접을 수 있게 둡니다. 메뉴 머리의 접기 버튼을 누르면 64px 아이콘 줄로 바뀌고, 맨 위에는 접기 버튼만 남습니다(로고·이름·숫자·묶음 제목은 숨김). 다시 누르면 펼쳐집니다. 마우스를 올리면 메뉴 이름이 툴팁으로 보입니다(`title`).
- 실제 앱에서는 `.app`에 `.is-collapsed`를 붙였다 떼고, 상태를 브라우저에 저장해 다음 접속 때도 유지합니다. 시안에서는 숨긴 체크박스(`.side-toggle`)로 같은 동작을 냅니다.
- 원격 화면처럼 넓게 봐야 하는 화면에서 접어 두면 본문이 184px 넓어집니다.
- 900px 이하 화면에서는 메뉴를 숨기고, 상단 바 왼쪽에 로고(`.topbar-brand`)를 보여 줍니다.
